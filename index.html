Assessor

O que é

O Assessor é um aplicativo de uso interno, instalado no computador de cada usuário. Ele organiza uma lista de trabalho a partir de planilhas do Google Planilhas que o próprio usuário já tem permissão para ver.

O acesso às planilhas é somente de leitura.

Privacidade

Os dados ficam somente no computador do usuário. O aplicativo não envia informações a servidores próprios nem a terceiros. Leia a política de privacidade.

Política de privacidade do Assessor

Vigente desde 26 de novembro de 2026.

O Assessor é um aplicativo de uso interno, instalado e executado no computador de cada usuário. Não há servidor central: o aplicativo não envia dados a servidores do desenvolvedor nem a terceiros.

Dados do Google que o aplicativo acessa

Com a autorização do usuário, o aplicativo usa o escopo https://www.googleapis.com/auth/spreadsheets.readonly para ler planilhas do Google Planilhas às quais o próprio usuário já tem acesso. O aplicativo não cria, altera nem apaga planilhas e não acessa e-mail, contatos, arquivos do Drive ou outros dados da conta.

Como os dados são usados

Os dados lidos servem apenas para mostrar ao próprio usuário, no computador dele, a lista de trabalho e o andamento de cada item. Ficam armazenados somente nesse computador. Não são vendidos, compartilhados, transferidos nem usados para publicidade.

O uso e a transferência de informações recebidas das APIs do Google seguem a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

Credenciais

A autorização concedida ao aplicativo fica guardada apenas no computador do usuário. O usuário pode revogá-la a qualquer momento em myaccount.google.com/permissions e apagar a pasta do aplicativo para remover todos os dados locais.
